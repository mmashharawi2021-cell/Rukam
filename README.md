# RukamGIS (v0.1 demo)

منظومة مستقلة لإدارة بيانات الركام الجغرافي في قطاع غزة **للعرض والاختبار فقط**.

> **تحذير:** جميع السجلات والمواقع والكميات والأوامر والرحلات افتراضية بالكامل. لا تمثل تقييمًا فعليًا لأي منطقة، ولا تصلح كأساس لتوجيه أعمال ميدانية أو قرارات تتعلق بالسلامة. التطبيق لا يحتوي قاعدة بيانات مركزية ولا مصادقة ولا صلاحيات فعلية؛ لذلك لا تدخل بيانات حقيقية أو حساسة.

## الوظائف المتوفرة
- خريطة Leaflet تفاعلية تعرض مواقع توضيحية مع اختيار الموقع وربطه بالسجل.
- لوحة مؤشرات تتغير مع البيانات المحلية (المواقع، الكميات التقديرية، الكميات المستلمة، حالات المراجعة).
- إضافة مواقع جديدة، البحث والتصفية، تحديث حالة الموقع، وتأشير مراجعة السلامة لأغراض التجربة.
- إنشاء أوامر عمل تجريبية، منع اعتماد أوامر لمواقع لم تُراجع سلامتها، وتحديث الحالات.
- سجل رحلات النقل مع تسجيل الاستلام، وحالات المطابقة، وربط كل رحلة بأمر عمل.
- متابعة الكميات المستلمة لكل مرفق تجريبي، وملخص التقارير.
- تصدير CSV وGeoJSON ونسخة احتياطية JSON واستيراد النسخ التجريبية؛ سجل تغييرات محلي.
- واجهة عربية RTL قابلة للاستخدام على الكمبيوتر والهاتف.

## التخزين والخصوصية
يُحفظ كل شيء في `localStorage` داخل متصفحك، ولا تتم مزامنة البيانات بين الأجهزة. يمكن تنظيف البيانات من واجهة الإعدادات. تسترجع خريطة الأساس مربعات صور من OpenStreetMap عبر اتصال المستخدم بالإنترنت. لا يوجد حساب مستخدم أو أمان مؤسسي؛ **غير صالح للإنتاج**.

## الاستقلال
هذا المستودع منفصل تمامًا عن مستودع `myprofile-` وعن GeoStudio Pro، ولا يشترك معهما بقاعدة بيانات أو إعدادات نشر.

## الهوية البصرية المعتمدة (Earth Theme)
الألوان المعتمدة: نحاسي `#C0674B`، زيتوني `#6B7A66`، رملي `#E8D8C3`، فيروزي `#5FA9A6`، وفحمي `#2F2F2F`. ملف `src/earth-theme.css` يطبّق النسق الرملي الفاتح على الواجهة الحالية دون تغيير توزيع الأقسام أو منطق الحفظ. ألوان حالات الخريطة وحالة المتصفح والأيقونة محدثة بما ينسجم مع التصميم. إن تكررت تعديلات الأنماط، يُحدّث هذا الملف بدلاً من نثر الألوان عبر الوظائف.

## v0.2 — الحصر الجغرافي وتقدير كميات الركام
- تبويب جديد «الحصر والرسم الجغرافي»: نقطة/مضلع، خط لقياس المسافة، تراجع آخر رأس، ومسح الرسم.
- تقدير حجم تدريبي من مساحة البصمة × متوسط السُمك × معامل تصحيح اختياري (1 افتراضيًا)، مع عرض نطاق عدم يقين يحدده المستخدم.
- المضلعات تُصدَّر فعليًا كـ Polygon في GeoJSON، وتُعرض في خريطة المواقع؛ مواقع v0.1 القديمة تظل نقاطًا.
- جميع المسودات تظل غير معتمدة وتحتاج تحققًا فنيًا قبل الاستخدام التشغيلي. خانة المخاطر معلومات وصفية فقط وليست تصريحًا بالسلامة.
- صيغة التخزين rukamgis-v01-demo-local-state ونسخ JSON القديمة لم تتغير؛ الحقول الجغرافية الجديدة اختيارية لضمان التوافق.
- استمارة الحصر تحفظ مسودة الإدخال محليًا؛ لا تتم مشاركة البيانات ولا تخزين الصور في هذه المرحلة.
- الاختبارات: npm test ثم npm run build.
